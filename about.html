About the data

Every code block you swing between in Binary Ninja is a real fragment of a compiled, Hikari-obfuscated x86-64 program. An offline analysis pipeline produced five datasets — one per level — and the game loads them in the browser from web_game_data/index.json. Nothing in the page parses a PE file, an LLVM module, a control-flow graph or an emulator trace; that work happened before the game existed, and the game only reads its result.

What is real

  • Addresses, entry RVAs and instruction listings on every block.
  • The raw basic blocks each visible block stands for.
  • String references, where the binary has any in plaintext.
  • Semantic call sites — authentication, firewall, scanner, watchdog, transfer, cleanup.
  • Hikari provenance on the unstable blocks: each one retains a strongly proven alteredBB classification from the obfuscator's own output.

One block is not one basic block

A visible platform is a chronological instance of a compact gameplay node. It commonly maps to several machine basic blocks, and where a program revisits the same logical node the trace gets a new forward platform with an incremented occurrence rather than a loop you have to walk backwards. The inspector shows the real count for whatever you are aiming at, and the analysis overlay (F1) shows the node and occurrence.

Which blocks crumble

Only blocks the dataset classifies as Hikari bogus control flow can collapse under you. Legitimate code that simply was not executed on the traced run is not fake, and the game never treats it as fake. Every level's successful route is completable without ever touching a crumbling block — that is checked by a test that drives the game's own physics.

Blackout has no strings

The fifth program was built with string encryption, so its exported blocks carry no plaintext strings at all. The game does not restore them, and does not substitute guesses drawn from the semantic event metadata. The mission is deliberately harder to read.

Layout is tuned; mappings are not

The delivered x/y coordinates passed an abstract reachability check that was explicitly not a rope-physics simulation, and at their supplied spacing the platforms very nearly form a continuous walkway. The game widens the horizontal gaps between route platforms with a monotone, deterministic transform before play, and leaves every y, every width, every id and every binary fact untouched. The analysis overlay reports the tuned and delivered link distances side by side.
